## 1. macOS Icons

[macosicons.com](https://macosicons.com) collects a large number of custom macOS app icons, free to download and use to personalize the Dock.

## 2. Emojipedia · Apple

[emojipedia.org/apple](https://emojipedia.org/apple) showcases how Apple-style emojis look across different iOS versions.

## 3. OSS Insight

[ossinsight.io](https://ossinsight.io) is a data visualization platform built by [PingCAP](https://www.pingcap.com) for GitHub open-source insights such as star growth, language trends, and contributor activity.

## 4. Vocatype

[vocatype.app](https://vocatype.app) is a typing-based vocabulary learning site that helps you memorize words while typing.

## 5. Claude's Sticker

[stickermule.com](https://www.stickermule.com/claudecode) features a variety of Claude-themed stickers, and the website design is also quite polished.

## 6. App Store Price Comparison

[appstoreprice.org](https://appstoreprice.org) helps compare prices and costs across different apps.

## 7. Swift Language Learning Tutorials

[Develop in Swift tutorials](https://developer.apple.com/tutorials/develop-in-swift/welcome-to-develop-in-swift-tutorials) is a great place to start learning Swift.

## 8. IP Check

[ipcheck](https://ipcheck.ing/#/) helps check your IP information.

## 9. KuKuTool Watermark Removal

[dy.kukutool.com](https://dy.kukutool.com/zh-Hans-SG) offers tools for removing watermarks from videos.

## 10. UI Gradient

[uigradients.com](https://uigradients.com/#Kyoto) is a collection of beautiful gradient palettes for design inspiration.

## 11. Fast

[fast.com](https://fast.com) is a quick website to test internet speed.

## 12. E-book

[OceanofPDF](https://oceanofpdf.com) is a website for downloading e-books.

More useful resources will be added over time.
